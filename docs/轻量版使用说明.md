# 内屏开关轻量版

轻量版和**同一版本**完整版使用相同功能代码，不包含 .NET 运行环境和虚拟显示驱动。轻量是下载包更小，不代表硬件适配范围更大。

## 什么时候选轻量版

- 电脑是 Windows x64，已经安装 **.NET 8 桌面运行时（x64）**。只装普通 .NET 运行时不够。
- 使用物理外接屏，或者仅用内屏但已经装好可用的虚拟显示驱动。首次准备驱动，优先从[最新发布](https://github.com/mgm2545551249-code/notebook-panel-switch/releases/latest)下载完整版压缩包。
- 已验证机型为**联想拯救者 R7000P 2025 款（83LT）**；其他机型应先测试。

## 下载后怎么用

1. 完整解压 `PanelSwitch-lite-win-x64.zip`，运行里面的 `PanelSwitch.exe`。需要安装入口时从解压目录运行 `安装.cmd`。单独下载的 `PanelSwitch-lite.exe` 适合直接运行。
2. 点击「控制」页的「15 秒关屏测试」，现场确认关屏、普通输入不点亮和自动恢复三项。
3. 日常切换默认 **Ctrl＋Alt＋F10**；紧急恢复默认 **Ctrl＋Alt＋F11**，它请求切回仅内屏，会暂时断开外接显示。两组都能在「设置」中修改。
4. 在「诊断」页查看显示环境；「高级工具」可导出诊断。更多说明见[使用说明](使用说明.md)。

若启动时提示缺少运行环境，安装所需的 .NET 8 桌面运行时（x64），或改用完整版。
