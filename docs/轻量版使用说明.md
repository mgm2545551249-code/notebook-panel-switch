# 内屏开关轻量版

轻量版与 v1.1.3 完整版采用相同功能代码，不附带 .NET 运行环境及虚拟显示驱动。

## 运行条件

Windows x64，需要安装 .NET 8 桌面运行时（Windows Desktop Runtime，x64）。仅安装普通 .NET 运行时不足以运行桌面界面。电脑已经安装对应运行时或包含它的开发工具时，无需重复安装。

缺少运行环境时，启动程序会显示系统运行环境提示。按提示安装对应桌面运行时，再启动程序。

## 使用

完整解压压缩包，运行其中的 PanelSwitch.exe。需要安装到当前用户目录时运行“安装.cmd”；运行“恢复显示.cmd”可执行恢复操作。

单独下载的 PanelSwitch-lite.exe 可直接运行；如需安装入口，请使用压缩包内原名为 PanelSwitch.exe 的版本。

默认快捷键为 Ctrl＋Alt＋F10。仅有内屏时仍需要已安装并可用的虚拟显示驱动；轻量版不包含驱动安装材料，首次配置这类电脑请使用完整版准备驱动。实体电源键控制仍需要管理员代理。

轻量版不会让关屏功能更通用，也不减少程序运行本身所需的系统组件。已测试机型为联想拯救者 R7000P 2025，其他电脑需要实测。首次使用执行十五秒关屏测试。

## v1.1.4 显示环境检测
启动时自动读取当前参数，也可点击检测显示环境。运行十五秒测试后，重新检测可查看最近一次关屏前后参数；历史样本不代表当前配置已验收。诊断导出包含该报告。检测本身不会改动系统配置。
