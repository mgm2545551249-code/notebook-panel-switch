# 实机验证摘要

验证日期：2026年11月14日。测试设备：联想83LT，Windows 11，RTX 5060 笔记本显卡，TL160ADMP20内屏。

| 配置项 | 已测试配置 |
|---|---|
| 笔记本型号 | 联想83LT |
| 操作系统 | Windows 11 专业版，10.0.26300，x64 |
| 显卡 | NVIDIA GeForce RTX 5060 Laptop GPU |
| 显卡驱动 | 32.0.15.9201 |
| 内屏型号 | TL160ADMP20 |
| 单内屏关屏路径 | 虚拟显示器维持可用目标，停用真实内屏显示路径 |
| 虚拟显示驱动 | Virtual Display Driver，内部版本11.30.4.434 |

以上为已验证的单一设备组合，不代表所有 Windows 笔记本通用。其他品牌型号、其他显卡驱动、Windows 10及ARM架构尚未实测；实体电源键事件和虚拟显示驱动的兼容性需要在目标设备验证。

|---|---|
| 自动检查 | 13项通过，0项失败 |
| 真实显示路径开关 | 50／50轮通过 |
| 普通鼠标及按键保持内屏停用 | 通过 |
| 快捷键关屏及恢复 | 真实输入联调通过 |
| 实体电源键关屏及恢复 | 用户现场确认通过 |
| 独立超时和异常退出恢复 | 通过 |
| 电源键策略接管、退出还原 | 通过 |
| 应用卸载和重新安装 | 通过 |

本机固件按钮名称为 `\_SB.PWRB`。系统上报的事件24和25分别为按钮通知与完成记录，通过电源事件掩码识别并去抖，不能只按设备管理器中的即插即用名称过滤。

物理外接屏插拔、电池供电切换、长时间音频和下载尚未完成对应场景验证。软件可确认显示路径停用和恢复，面板的实际发光状态需现场观察。

本摘要保留测试结论，不提交含用户名、绝对安装路径或设备实例完整标识的原始日志。
