# 内屏开关

这款软件为当前联想笔记本提供内屏开关、中文托盘、自定义快捷键和实体电源键接入。无需另外安装 .NET。

默认快捷键是 **Ctrl＋Alt＋F10**。首次启用实体电源键时启动管理员代理；开机启动默认关闭。

## 开始使用

双击发布目录中的安装入口，程序会安装到当前用户的应用目录，并创建开始菜单快捷方式。也可以直接运行发布目录中的 PanelSwitch.exe。

1. 按 Ctrl＋Alt＋F10 关闭内屏，再按一次恢复。
2. 在“开关快捷键”输入框中按下新的组合键，点击“保存快捷键”。发生冲突时保留原快捷键。
3. 实体电源键控制启用后，短按电源键切换内屏；长按的硬件行为保持原样。
4. 勾选“登录后自动运行”可在登录时启动。关闭设置窗口后程序留在托盘；从托盘选择“退出并恢复”会恢复显示及被接管的电源键策略。

## 没有外接屏时

本机的内屏常规独立电源接口读取未通过，因此采用虚拟显示驱动维持一个可用显示目标，再停用真实内屏路径。该方式已在本机完成五十次显示路径开关及恢复测试。

本机已安装并验证虚拟显示设备状态正常。换电脑时需先点击“安装虚拟显示驱动”，安装成功后保持“允许使用已安装的虚拟显示器维持单内屏关屏”勾选。程序不会停用唯一的可用显示路径。

真实面板是否停止发光，需要现场观察确认；软件诊断和截图只用于检查显示路径状态。

## 连接物理外接屏时

关闭内屏时保留外接显示路径，键鼠继续操作外接屏。内屏上的窗口可能迁移到其他屏幕；恢复时软件恢复原显示路径并尽力恢复窗口位置。窗口关闭、权限差异及程序自行移动窗口都可能影响位置恢复。

拔掉外接屏或发生显示设备变化时，软件优先恢复可用内屏。物理外接屏插拔、电池供电和音频下载持续性仍列为现场验收项，见[实机验证摘要](实机验证摘要.md)。

## 恢复和卸载

- 快捷键未恢复时，可运行发布目录中的恢复入口。
- “十五秒独立关屏测试”由独立恢复进程兜底，超时或主程序异常退出后恢复显示。
- 软件卸载使用发布目录中的卸载入口。请从交付包运行卸载入口；它会退出常驻程序、恢复被接管的设置并移除已安装的应用文件。
- 虚拟显示驱动单独使用发布目录中的驱动卸载入口。共享驱动仓库和发布者证书保留，不影响其他软件。
- 源码回滚脚本只用于开发验证，与屏幕恢复工具用途不同。

## 日志与诊断

设置窗口提供诊断导出及打开日志目录入口。配置、恢复记录和运行日志位于当前用户本地应用数据的“内屏开关”目录。

日志记录开关状态、显示设备、错误及电源键事件，不记录普通键盘输入内容。电源键接入只识别系统 ACPI 提供程序的按钮事件，不将普通关屏、鼠标唤醒或电源策略变化误认成实体按钮。

程序退出时按原电源方案恢复接电、电池两种短按策略；运行期间如果用户把策略改成其他值，软件保留用户修改并记录日志。

## 源码构建

使用 .NET 8 SDK，在交付目录执行：

```powershell
dotnet publish ./src/PanelSwitch/PanelSwitch.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./重新构建
```

构建后的程序用于测试或便携运行。需要使用驱动安装入口时，把交付包“发行版”中的“驱动”文件夹放在新程序旁。
