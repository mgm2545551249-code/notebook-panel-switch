# 内屏开关使用说明

## 选择并启动

1. 打开[最新发布](https://github.com/mgm2545551249-code/notebook-panel-switch/releases/latest)。首次使用优先下载完整版压缩包；如果已经安装 .NET 8 桌面运行时（x64），且不需要附带的虚拟显示驱动，可用轻量版。
2. 完整解压压缩包，运行 `PanelSwitch.exe`。如需安装到当前用户目录并创建开始菜单入口，从解压目录运行 `安装.cmd`。
3. 先在「控制」页点「**15 秒关屏测试**」。确认实机能停止发光、普通键鼠不会重新点亮，以及超时能恢复，再日常使用。截图和状态检测不能代替现场观察。

## 控制、设置和诊断

| 操作 | 对应入口 |
| --- | --- |
| 日常开关 | 默认 **Ctrl＋Alt＋F10**，或点击「控制」页的开关按钮。 |
| 紧急恢复 | 默认 **Ctrl＋Alt＋F11**，或点击窗口底部「紧急恢复内屏」。请求切回仅内屏，外接屏会暂时停止显示。 |
| 两组快捷键 | 「设置」内分别选修饰键和按键，再保存。发生重复或系统占用时会保留原有设置。 |
| 实体电源键 | 「设置」内启用。需要管理员代理；只有已适配且通过现场验证的机型，才能用短按切换内屏。 |
| 登录后自动运行 | 「设置」内开关。默认关闭；启动后在托盘运行。若被 Windows 禁用，请先在系统「应用 → 启动」中检查。 |
| 检查显示环境、导出诊断 | 「诊断」页；导出入口在「高级工具」。公开分享前建议遮盖本机路径和设备标识。 |

关闭窗口不会退出程序。从托盘选择「退出并恢复」可恢复显示及尝试还原被接管的电源键设置。

## 只有内屏，或接了外接屏

- **只有内屏：** 当前方案通常需要可用的虚拟显示驱动。用完整版打开「诊断 → 高级工具 → 检查／安装虚拟显示驱动」，按提示授权或重启，并保持设置中的虚拟显示器选项开启。
- **有物理外接屏：** 日常关屏应保留外接显示，窗口可能迁移。恢复时会尝试恢复布局；分辨率、缩放、驱动和应用自身行为都可能影响结果。
- **兼容性：** 已验证机型为联想拯救者 R7000P 2025 款（83LT）。其他机型、热插拔、电池切换和特定游戏请按各自场景验证，见[实机验证摘要](实机验证摘要.md)。

## 恢复与卸载

- **一般恢复：** 再按一次日常开关键；从解压目录运行 `恢复显示.cmd` 可尝试恢复已有显示记录并唤醒显示器。
- **没有恢复记录或仍找不到内屏：** 程序运行时使用紧急快捷键。它不依赖已有恢复记录，与 `恢复显示.cmd` 的行为不同。紧急恢复会暂时退出外接显示；必要时可用 Windows 的「仅电脑屏幕」投影模式。
- **卸载：** 先确认内屏已经亮起，再从解压目录运行 `卸载.cmd`。虚拟显示设备使用完整版单独的卸载入口；移除前确认已有可用的实体显示输出。该入口保留共享驱动仓库和发布者证书。

日志和配置在当前用户的本地应用数据「内屏开关」目录。程序不记录普通键盘输入内容。开发和构建请参考[项目首页](../README.md)。
